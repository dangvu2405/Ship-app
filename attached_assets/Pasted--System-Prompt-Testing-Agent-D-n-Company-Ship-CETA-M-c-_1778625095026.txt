## 3. TENANT & AUTH CONTEXT — BẮT BUỘC CÓ TRONG MỌI FEATURE TEST

### 3.1 Setup chuẩn cho một feature test

```php
<?php

use App\Models\User;
use App\Models\Company;
use Laravel\Sanctum\Sanctum;
use Illuminate\Foundation\Testing\RefreshDatabase;

uses(RefreshDatabase::class);

beforeEach(function () {
    // 1. Tạo tenant (company)
    $this->company = Company::factory()->create(['status' => 'active']);

    // 2. Tạo user có role phù hợp với test
    $this->admin = User::factory()->create([
        'role'       => 'admin',
        'status'     => 'active',
        'company_id' => $this->company->id,
    ]);

    // 3. Authenticate qua Sanctum
    Sanctum::actingAs($this->admin);

    // 4. Set tenant header — BẮT BUỘC cho mọi request nghiệp vụ
    $this->withHeader('X-Tenant-ID', (string) $this->company->id);
});
```

### 3.2 Helper tạo user theo role

```php
// Dùng trong test khi cần test phân quyền
function makeUser(string $role, ?Company $company = null): User
{
    return User::factory()->create([
        'role'       => $role,
        'status'     => 'active',
        'company_id' => $company?->id ?? Company::factory()->create()->id,
    ]);
}

function actAs(string $role, ?Company $company = null): User
{
    $user = makeUser($role, $company);
    Sanctum::actingAs($user);
    return $user;
}
```

## 6. FRONTEND TEST CONVENTIONS

### 6.1 Build & Lint — Cổng vào bắt buộc

Trước mọi review hoặc merge, hai lệnh sau phải pass clean:

```bash
cd ship-app

```

**Lỗi TypeScript phổ biến cần kiểm tra:**
- `any` ẩn trong service/hook — thay bằng type cụ thể.
- `response.data.data` nhầm tầng (single vs paginated envelope).
- `useQuery` thiếu `enabled` guard khi `id` có thể `undefined`.
- `useMutation` không handle `onError` → lỗi không hiển thị với user.

### 6.2 Smoke Test Checklist — Chạy trên browser

Sau mỗi thay đổi liên quan đến flow chính, kiểm tra thủ công các state sau:

| State | Cách kiểm tra |
|-------|--------------|
| Loading | Giả lập mạng chậm (DevTools → Network → Slow 3G), table phải có spinner |
| Empty | Xóa hết data của tenant, page phải hiện "Không có dữ liệu" đúng ngôn ngữ |
| Error | Block request trong DevTools (Network → Block URL), phải có error message thân thiện |
| Success | Thực hiện action thành công, toast xuất hiện, data refresh đúng |
| 401 | Xóa token trong localStorage, reload → redirect về `/login` |
| 403 | Gửi X-Tenant-ID sai, phải có thông báo và redirect đúng |

### 6.3 Smoke Test — Các flow ưu tiên cao

```
[ ] Login: email/password → token lưu đúng storage (remember/session)
[ ] Select tenant: user nhiều company → màn chọn tenant → load đúng data
[ ] Trip list: load, filter theo status, paginate, search theo keyword
[ ] Trip assign: mở modal → chọn xe/tài xế từ /available → PATCH /assign → toast + refresh
[ ] Trip lifecycle: start → deliver → complete (theo thứ tự, không skip)
[ ] Upload file: chọn file → POST /upload → URL hiển thị đúng trong form
[ ] Dispatch board: load với date param → unassigned trips hiển thị đúng
[ ] Notification: unread-count badge → click read → count giảm
[ ] Logout: clear token + tenant → redirect login → không còn auth header
[ ] Tenant switch: đổi tenant → queryClient.clear() → data mới load
```

### 6.5 Anti-patterns cần phát hiện khi review

```typescript
// ❌ Tạo axios instance mới
const myAxios = axios.create({ baseURL: '...' });

// ❌ Gọi fetch() cho internal API
const res = await fetch('/api/trips');

// ❌ Nhầm tầng envelope — paginated trả { data: { data: [], meta: {} } }
const trips = response.data;           // Sai với paginated
const trips = response.data.data;      // Đúng với paginated
const trips = response.data.data.data; // Đúng chỉ khi paginated nested

// ❌ Action endpoint dùng POST thay vì PATCH
await api.post(`/trips/${id}/assign`);  // Sai

// ✅ Đúng
await api.patch(`/trips/${id}/assign`); // Đúng

// ❌ Không guard enabled khi id undefined
useQuery({ queryKey: ['trips', id], queryFn: () => tripService.get(id!) });

// ✅ Đúng
useQuery({
  queryKey: ['trips', id],
  queryFn: () => tripService.get(id!),
  enabled: !!id,
});

// ❌ Không handle onError trong mutation → lỗi im lặng
useMutation({ mutationFn: tripService.assign });

// ✅ Đúng
useMutation({
  mutationFn: tripService.assign,
  onSuccess: () => { qc.invalidateQueries({ queryKey: ['trips'] }); message.success('...'); },
  onError: (err: any) => { message.error(err?.response?.data?.message ?? 'Lỗi xảy ra'); },
});

// ❌ Hardcode text tiếng Việt trong JSX
<Button>Phân công</Button>

// ✅ Đúng
const { t } = useTranslation();
<Button>{t('trip.action.assign')}</Button>
```

## 7. API INTEGRATION TEST SCENARIOS

Các kịch bản test tích hợp thực tế — chạy với Postman hoặc script `curl`:

### 7.1 Auth Flow

```bash
# 1. Login
POST /api/auth/login
Body: { "email": "admin@abctransport.com", "password": "password" }
Expect: 200 + { token, refreshToken, user, tenants }

# 2. Me
GET /api/auth/me
Header: Authorization: Bearer {token}
        X-Tenant-ID: {company_id}
Expect: 200 + { user, company, permissions, tenants }

# 3. Gọi không có token
GET /api/trips
Expect: 401

# 4. Gọi không có X-Tenant-ID
GET /api/trips
Header: Authorization: Bearer {token}
Expect: 403 hoặc empty data (tùy impl tenant sentinel)
```

### 7.2 CRUD cơ bản (ví dụ với Vehicles)

```bash
# List (có tenant scope)
GET /api/vehicles?page=1&per_page=10
Expect: 200 + { data: { data: [...], meta: {...} } }

# Create
POST /api/vehicles
Body: { "plate_number": "51C-12345", "vehicle_type_id": 1, ... }
Expect: 201 + { data: { id, company_id: {current_tenant}, ... } }

# Update
PATCH /api/vehicles/{id}
Body: { "status": "maintenance" }
Expect: 200 + { data: { status: "maintenance" } }

# Available filter
GET /api/vehicles/available
Expect: 200 — chỉ xe có status = active, không đang in_progress

# Delete (soft)
DELETE /api/vehicles/{id}
Expect: 200
GET /api/vehicles/{id}  → Expect: 404 (soft deleted)
```

### 7.4 Cross-Tenant Isolation Test


## 8. KNOWN GAPS CẦN TEST ĐẶC BIỆT

Các điểm sau có rủi ro cao — phải có test riêng để detect regression:

| # | Gap | Test cần viết |
|---|-----|---------------|
| 1 | Trip action method (POST vs PATCH) | Test phải dùng `patchJson`, không dùng `postJson` cho assign/start/... |
| 2 | Refresh token key: backend `refreshToken` (camelCase) vs frontend expect `refresh_token` | Feature test kiểm tra response shape của `/auth/login` có key `refreshToken` |
| 3 | `/vehicles/available` vs `/vehicles/{id}` route order | Integration test: gọi GET /vehicles/available phải trả list, không 404 |
| 4 | `driver-work-schedules` URL nhưng resource name `work-schedules` | Test URL bằng `driver-work-schedules` — không dùng `work-schedules` |
| 5 | Payroll endpoints khai báo ở FE nhưng chưa có route BE | Đánh dấu skip/pending test cho payroll generate, approve, export |
| 6 | Invoice `send-cqt`, `export-pdf`, `send-email` chưa implement BE | Tương tự — skip hoặc test returns 404/405 |
| 7 | Tenant sentinel `-1` khi không resolve được tenant | Test: authenticated user không thuộc company nào → list returns empty, không lỗi 500 |
| 8 | `LoginLog`/`ExportLog` model nhưng bảng không tồn tại | Test không được trigger code path dùng hai model này |

```php
// Gap 2: Kiểm tra response shape của login
it('login response contains refreshToken key (camelCase)', function () {
    $response = $this->postJson('/api/auth/login', [
        'email'    => $this->admin->email,
        'password' => 'password',
    ]);

    $response->assertOk()
             ->assertJsonStructure(['data' => ['token', 'refreshToken', 'user', 'tenants']]);

    // Đảm bảo key camelCase tồn tại (không phải chỉ snake_case)
    expect($response->json('data.refreshToken'))->not->toBeNull();
});

// Gap 3: /vehicles/available không bị router nhầm sang /vehicles/{id}
it('GET /vehicles/available returns a list not a single resource', function () {
    Vehicle::factory(3)->active()->create(['company_id' => $this->company->id]);

    $this->getJson('/api/vehicles/available')
         ->assertOk()
         ->assertJsonStructure(['data' => ['data', 'meta']]);   // list shape, không phải single
```

- Happy path (1 case)

- Tenant isolation (đọc cross-tenant → 404/empty)

**Bước 3 — Viết test theo thứ tự ưu tiên**
1. Auth/tenant test (luôn đầu tiên)

5. Edge cases

## 12. VÍ DỤ HOÀN CHỈNH

### Yêu cầu: "Viết test cho endpoint PATCH /trips/{id}/assign"

**Phạm vi test:** Trip assign action, business rules về vehicle/driver availability, tenant isolation, auth.

**Test cases:**
- [x] Happy path: assign thành công, status → assigned, driver_id + vehicle_id đúng
- [x] 401 không có token
- [x] 403 không có X-Tenant-ID
- [x] 422 khi trip không ở trạng thái pending/assignable
- [x] 422 khi vehicle không active
- [x] 422 khi vehicle đang in_progress ngày hôm đó
- [x] 404 khi trip thuộc tenant khác
- [x] Trip status history được ghi nhận

```php
<?php

use App\Models\{Company, User, Driver, Vehicle, Trip};
use Laravel\Sanctum\Sanctum;
use Illuminate\Foundation\Testing\RefreshDatabase;

uses(RefreshDatabase::class);

beforeEach(function () {
    $this->company = Company::factory()->create(['status' => 'active']);
    $this->admin   = User::factory()->create(['role' => 'admin', 'status' => 'active', 'company_id' => $this->company->id]);
    Sanctum::actingAs($this->admin);
    $this->withHeader('X-Tenant-ID', (string) $this->company->id);

    // Fixtures
    $this->driver  = Driver::factory()->create(['company_id' => $this->company->id, 'available_status' => 'available']);
    $this->vehicle = Vehicle::factory()->active()->create(['company_id' => $this->company->id]);
    $this->trip    = Trip::factory()->pending()->create([
        'company_id'     => $this->company->id,
        'scheduled_date' => today()->toDateString(),
    ]);
});

it('assigns trip successfully and returns assigned status', function () {
    $this->patchJson("/api/trips/{$this->trip->id}/assign", [
        'driver_id'  => $this->driver->id,
        'vehicle_id' => $this->vehicle->id,
    ])
    ->assertOk()
    ->assertJsonPath('success', true)
    ->assertJsonPath('data.status', 'assigned')
    ->assertJsonPath('data.driver_id', $this->driver->id)
    ->assertJsonPath('data.vehicle_id', $this->vehicle->id);

    $this->assertDatabaseHas('trips', [
        'id'        => $this->trip->id,
        'status'    => 'assigned',
        'driver_id' => $this->driver->id,
    ]);
});

it('records trip status history on assign', function () {
    $this->patchJson("/api/trips/{$this->trip->id}/assign", [
        'driver_id'  => $this->driver->id,
        'vehicle_id' => $this->vehicle->id,
    ])->assertOk();

    $this->assertDatabaseHas('trip_status_histories', [
        'trip_id'     => $this->trip->id,
        'from_status' => 'pending',
        'to_status'   => 'assigned',
    ]);
});

it('returns 401 when not authenticated', function () {
    $this->withoutToken()
         ->patchJson("/api/trips/{$this->trip->id}/assign", [
             'driver_id' => $this->driver->id, 'vehicle_id' => $this->vehicle->id,
         ])
         ->assertUnauthorized();
});

it('returns 403 when X-Tenant-ID missing', function () {
    $this->withoutHeader('X-Tenant-ID')
         ->patchJson("/api/trips/{$this->trip->id}/assign", [
             'driver_id' => $this->driver->id, 'vehicle_id' => $this->vehicle->id,
         ])
         ->assertForbidden();
});

it('returns 422 when trip is not in pending state', function () {
    $completedTrip = Trip::factory()->completed()->create(['company_id' => $this->company->id]);

    $this->patchJson("/api/trips/{$completedTrip->id}/assign", [
        'driver_id'  => $this->driver->id,
        'vehicle_id' => $this->vehicle->id,
    ])->assertUnprocessable();
});

it('returns 422 when vehicle is not active', function () {
    $inactiveVehicle = Vehicle::factory()->maintenance()->create(['company_id' => $this->company->id]);

    $this->patchJson("/api/trips/{$this->trip->id}/assign", [
        'driver_id'  => $this->driver->id,
        'vehicle_id' => $inactiveVehicle->id,
    ])->assertUnprocessable();
});

it('returns 422 when vehicle is in_progress on same day', function () {
    Trip::factory()->inProgress()->create([
        'company_id'     => $this->company->id,
        'vehicle_id'     => $this->vehicle->id,
        'scheduled_date' => today()->toDateString(),
    ]);

    $this->patchJson("/api/trips/{$this->trip->id}/assign", [
        'driver_id'  => $this->driver->id,
        'vehicle_id' => $this->vehicle->id,
    ])->assertUnprocessable();
});

it('returns 404 when trip belongs to another tenant', function () {
    $otherTrip = Trip::factory()->pending()->create([
        'company_id' => Company::factory()->create()->id,
    ]);

    $this->patchJson("/api/trips/{$otherTrip->id}/assign", [
        'driver_id'  => $this->driver->id,
        'vehicle_id' => $this->vehicle->id,
    ])->assertNotFound();
});
```
